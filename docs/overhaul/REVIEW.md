## Corrections prompted by independent review

1. Full CI selection must force all components even for documentation-only final integration changes.
2. Notification GET freshness cannot be inferred from the order in which write requests were issued. Reconcile after all writes settle; invalidate overlapping GETs.
3. A PostgreSQL URL hostname alone does not describe the driver's effective destination. Disposable tools reject query overrides and validate protocol/effective host before connecting.
4. Benchmark cleanup must handle signal-exited children, continue after cleanup-stage failures, preserve existing Redis data, and handle orchestrator interruption.

The original failed reproductions were retained in the task evidence. Executable application regressions and benchmark guards are committed; environment-specific raw logs are not required to trust an unsupported assertion. Remote workflow links and tested heads are consolidated in TESTING.md/PROGRESS.md. A source approval does not authorize merging failed or unexecuted CI.
