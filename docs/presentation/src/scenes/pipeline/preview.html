그럼 제출 버튼을 누른 뒤 실제로 무슨 일이 일어나는지 따라가 볼게요. 오른쪽은 그 순간에 도는 실제 코드예요.

API 서버는 제출을 ‘대기’로 저장하고, 번호표 줄에는 코드 없이 제출 번호만 넣은 뒤 바로 ‘접수됐다’고 답해요.

채점 워커가 번호표를 뽑으면 60초 채점 예약을 받아 코드와 테스트를 가져가고, go-judge라는 밀폐된 방에서 공개 예제부터 하나씩 실행해 정답과 비교해요.

결과가 오면 판정을 저장하고 첫 정답이면 XP를 줘요. 화면은 그동안 2초마다 다시 물어보다가 결과를 띄웁니다.
