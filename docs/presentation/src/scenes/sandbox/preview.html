이번엔 격리 실행이에요. 일부러 위험한 코드 다섯 개를 넣어 볼게요.

      
끝없이 도는 코드는 시간 제한에서, 메모리를 계속 먹는 코드는 메모리 제한에서 강제로 멈추고, 출력이 100만 바이트에 닿으면 출력 초과예요.

      
자기 자신을 복제하는 코드는 64개에서 막히고, 인터넷은 아예 연결이 안 돼요.

      
예전엔 직접 만든 감시기가 2ms마다 메모리를 쟀는데, 지금은 go-judge가 운영체제 기능으로 가두고, 채점 워커에는 Docker 권한도 없습니다.
